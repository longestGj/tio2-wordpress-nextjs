# Malaysia 询盘业务

日期：2026-09-08。状态：D16业务说明样稿，待审阅。网站`tio2-my`，页面`CONV-RFQ`，路径`/request-a-quote/`。本轮依据本地合同及代码整理；业务批准与当前运行状态须按[来源索引](../../sources.md)核对，本文不授予新批准。

## 目标与范围

询盘面向提供采购需求的企业访客，收集产品、应用、数量、目的地和联系信息，供团队评估并作商业回复。合同文案支持此目标；不承诺自动报价、成交、响应时限或库存。

样品和资料申请使用独立入口，本领域不替代它们。2026-09-08同步main后，当前RFQ表单经`/api/rfq/submit`服务端校验、解析来源并转交Web3Forms，没有据此建立内部CRM、询盘数据库或订单系统。技术链路见[软件架构](../../../../software-architecture.md#6-表单的数据流与外部依赖)。

## 业务流程与状态

直接进入或从产品/内容入口进入 → 应用允许的预填 → 用户补充与修改 → 校验 → 提交 → 显示确认或未确认结果。完整跨页场景见[journeys](../../journeys.md)。

| 当前实现状态 | 用户可观察结果 | 解释边界 |
|---|---|---|
| 待填写/校验错误 | 展示表单；错误提示并保留其他输入 | 输入合法不等于提交成功 |
| 提交中 | 控件及提交按钮禁用 | 防当前页面重复操作，不证明服务端业务去重 |
| receipt_confirmed | 显示确认收到请求的文案 | 适配器要求HTTP 200、JSON且success为true；仅证明服务商响应，不证明邮箱收件 |
| submission_unconfirmed | 显示失败与重试提示，保留信息 | 网络、超时或异常响应不能伪装成已收到 |
| service_unavailable | 提示暂不可用且未提交 | 当前缺少接收配置时使用该状态 |

## 业务数据与规则

以下是仓库合同与校验实现的摘要；准确字段、选项、文案及限制引用[RFQ合同](../../../../../wordpress/plugins/tio2-site-model/config/tio2-my-rfq-page.json)，不在这里维护另一份选项清单。

| 数据 | 语义及当前约束 |
|---|---|
| 产品/Grade、Application | 必填且属于合同选项；产品包含不确定/需要帮助的选项，不把未知参数当成合法产品 |
| 数量 | 大于0，固定单位MT；不从此推断最低订单量 |
| 目的国家/地区 | 采购目的地，必填；不代表买方公司所在地，区域预填差异见未决项 |
| 目的港/城市 | 可选，已知时填写 |
| 公司、联系人、业务邮箱 | 必填并执行合同长度/格式校验；邮箱格式通过不代表身份或送达验证 |
| 电话、网站、补充要求 | 可选；网站填写时需完整HTTP(S)地址；遵守合同长度及非敏感信息提示 |
| 来源与提交身份 | source_page_id等允许的上下文，以及site_scope、page_id、workflow_type、locale、request_token |

本次main同步后，实际RFQ来源由同源Referer路径允许列表及签名HttpOnly cookie在服务端确定，主表单不提交客户端source_page_id。公开业务字段的预填由表单组件处理；旧预填辅助函数不等于当前主表单完整运行链路。此处记录合入实现，不将本次同步视为新业务规则的独立批准。

预填只接受当前允许的选项与上下文；可编辑字段不替用户断定采购事实。当前预填实现阻止M-2377与Specialty Materials的自动组合推断，但这不等于禁止用户手动选择该组合。数量与目的地不能从其他页面的展示内容任意推导。
