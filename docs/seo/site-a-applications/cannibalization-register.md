# Cannibalization and Page-Boundary Register

## Risk scale

- `High`: two pages can plausibly rank for the same core query unless headings, internal anchors, and content sections enforce different intent.
- `Medium`: overlap is manageable but requires consistent terminology and internal linking.
- `Low`: normal semantic overlap within a hierarchy.

## Merge recommendations

No immediate merge is recommended. The current 28-page structure is frozen, and the research supports distinct intent for most Details. The Printing Inks and Decorative Paper hierarchies need particularly disciplined copy boundaries, but premature merging would remove useful commercial/technical separation before Search Console data exists.

## Split candidates, in priority order

1. Powder Coatings and Coil Coatings.
2. Soft PVC and Solar Backsheet.
3. Optical Glass, Battery Materials, and other Functional Materials.
4. Marine, Aerospace, and general Protective Coatings if future demand differentiates them.

A split should require current demand evidence, a clear product/application boundary, sufficient approved content, and an internal-link update plan. Keyword research alone does not authorize a new route.
