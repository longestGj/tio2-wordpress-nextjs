# Keyword Decision Log

Each decision below corresponds to a `decisionId` in `site-a-applications-keyword-map.json`. Search volume is not the only selection criterion. Page fit, current SERP composition, hierarchy, and avoidance of cross-page conflict take priority. The selected phrase is a target query, not a requirement for mechanical exact-match repetition.
