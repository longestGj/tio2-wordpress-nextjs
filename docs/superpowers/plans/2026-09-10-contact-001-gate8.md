> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the approved TiO₂ Malaysia `/contact/` page, its scope-bound CMS/render chain, search/Schema output, local fail-closed six-field form shell, and reproducible Gate 8 evidence.

**Architecture:** Add a `tio2_contact_page` WordPress singleton whose GraphQL projection is accepted only for `site_scope=tio2-my`, published status, `/contact`, and the approved contract version. A Next.js Server Component loads the DTO, metadata and JSON-LD; page-owned client code implements validation, pending, failure and manual retry through a same-origin route that repeats validation and never forwards externally or returns success while the Contact processor decision is open. The page consumes the existing Malaysia Header/Footer and Consent owners.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, WordPress/PHP 8.1, WPGraphQL, Vitest, Testing Library, Playwright.
