## 1. 已确认的三个缺口

1. 管理员归档只包含固定服务器程序，没有安装本轮 WordPress 插件和 PHP 内容导入文件，也没有内容运行容器及 hooks 的安装实现。
2. `ReleaseController.system()` 没有 CMS 平台升级适配器；不能把 CMS 插件变更装进前台包。
3. `phase1_migration.py`、`site_frontend_adapter.compatibility_candidate()` 绑定旧提交 `8bf2a3d4…`。`release_controller.py` 还明确拒绝新 v2 前台候选；`deployment_core.require_compatible_trees()` 要求旧新 WordPress 文件完全相同。只补安装容器或替换旧提交常量，都不能正确发布这次前台与 CMS 更新。

## 2. 方案选择

建议：在现有固定控制器旁补一个适用于当前部署拓扑的管理员安装/升级入口，并接通登记网站的新前台候选。复用备份、锁、容器、Nginx 切换和回执；不另建通用 Campaign 执行器。

只修管理员包无法完成本轮上线；实现全部五类通用发布适配器则超出当前需求。上述建议覆盖实际缺口，其他网站通过各自后续登记与验收接入，不复制程序、不宣称已部署。

## 3. 管理员安装/升级

提供独立 `plan / apply / status / rollback` 安装接口。仅管理员可安装程序和权限；日常发布继续使用 deploy 与固定命令。计划绑定准确输入文件哈希、现有程序/插件、容器、数据库、网站和预期变更。apply 前重新核对；不把计划时的现场当成永久事实。

安装固定内容导入 PHP 与当前批准插件，创建密封只读导入容器和独立私密凭据；常规 WordPress 保持低权限。安装真实身份、维护、刷新及页面验证 hooks，并生成受保护的内容运行登记。配置与密钥不进入 Git 或普通回执。插件、镜像和程序均来自准确冻结工件，不能读取未提交工作树或临时执行上传脚本。

CMS 插件升级前暂停共享数据库写入，备份整库和旧插件/配置，验证备份可恢复；本轮不改变业务内容、不批量重新运行 seed。升级失败恢复旧插件与配置；若确实发生数据库变化，只在同一暂停窗口内恢复本次整库备份。恢复验证失败继续保持维护，不开放写入。未知的生产资源归属在计划阶段拒绝，不猜测容器或路径。

维护/验证 hooks 操作真实环境：目标站维护页返回 503，独立内部入口仍可验证；共享数据库写入统一暂停。缓存刷新使用实际签名接口；页面验证读取实际正文、SEO、状态和 sitemap。身份来自当前镜像、Build、CMS 插件与配置。所有能力检查通过后才能登记为可用。

## 4. 新前台候选入口（本次新增接口范围）

保留旧兼容事务及证据，另接通已有候选信封的新候选流程。只有前次事务终结并核对当前线上身份后，才能准备下一批；旧事务未完成时不能覆盖其状态或借新安装跳过恢复。

新候选绑定网站、准确提交、Build、配置、当前已升级 CMS 合同、上一生产回执、预发布证据与文件哈希。复用现有 stage/activate/verify/rollback 的实际容器与 upstream 操作，补齐新信封到运行层的验证映射；不能通过删除 CMS 一致性检查或伪造旧候选证据接入。

先验证旧前台能够读取升级后 CMS 的原内容，再发布新前台。若不兼容，须在同一维护窗口内完成这两项升级并验证恢复顺序；不得在无测试依据时宣称插件向后兼容。新前台回退到旧前台前，也要验证旧前台与当前 CMS 相容性。

## 5. 最小测试与完成条件

- TDD：包哈希错误、生产身份漂移、错误 scope、未完成旧事务、新候选重放与未知资源均拒绝。
- 安装隔离测试：真实 Docker WordPress/MariaDB，从旧插件升级到新插件，检查原内容不变；验证管理员凭据不进入 HTTP WordPress，导入容器只读、维护页和内部读取、写入暂停与正确解除。
- 故障测试：备份失败不得升级；插件替换、导入容器创建、配置登记中断可恢复；只清理本次拥有的资源。真实恢复旧插件/数据库，并核对其他 scope。
- 新前台连续两次发布演练：使用不同提交/Build，走真实候选、备份、部署、切换和回退；不能仅替换 `COMPATIBILITY_COMMIT` 常量或使用模拟发布器。
- 沿用真实 CMS→WPGraphQL→Next 内容成功/失败恢复测试，确认安装产物就是被测程序，不以测试夹具 hooks 代替生产 hooks。
- 开发准确复审、合入 develop、写开发回执后，发布负责人重新冻结版本。全站验收为 56 页面加 Thank You 和新版 404，三个视口、真实三表单及对应收件证据；历史通过不替代新版本验收。
