## Menu capture anomaly and bounded recheck

Initial IN/INK/PAPER menu captures lacked all menu text and chrome; COAT was partially painted. These observations were promptly reported before any clean visual claim. Original nine menu PNGs and records were copied into `.tmp/editorial-menu-recheck-ou9ABl/` before replacement. A 500ms settle with the default headless GPU capture still produced intermittent omissions. Playwright `page.screenshot({scale:'device'})` returned a 712px bitmap despite unchanged native metrics, so it was rejected before use as final evidence. Headless CDP `fromSurface:false` returned a blank window and was also rejected. Intermediate records/captures are archived in `.tmp/editorial-menu-recheck-vYV8di/`, `.tmp/editorial-menu-recheck-R1zJCb/` and `.tmp/editorial-menu-recheck-3EB30P/`.

The successful bounded run used Chromium `--disable-gpu`, persistent context `viewport:null`, extension `tabs.setZoom(2)`, `page.bringToFront()`, 500ms compositor settling, and direct CDP `Page.captureScreenshot` with `fromSurface:true` and `captureBeyondViewport:false`. Native zoom was queried again and all window/CSS/DPR metrics compared immediately before and after every screenshot. No DOM, CSS, device metrics, viewport dimensions or page content were changed to force rendering. All nine URLs returned 200 and their HTML contained the same build ID. The default-GPU omissions did not occur in any of the 18 final images. This supports a headless capture/compositor issue; it does not establish a page implementation defect or isolate a Chromium internal root cause.

The [bounded recheck script](native-menu-recheck.mjs), run from the worktree root, completed all nine pages with exit 0. For each page, real browser keyboard events checked Close → Shift+Tab top RFQ → Shift+Tab final RFQ (100% in viewport) → Tab top RFQ → Tab Close → Escape original trigger. No link was activated and no form was submitted. The [complete result objects](native-menu-recheck-results.json) and per-page measurements are retained in the evidence directory. The existing native test's capture harness now records the software compositor and active-page settle method; its [focused ESLint check](native-harness-eslint.log) passed. The full nine-page native spec was not rerun after this harness-only edit; the successful bounded recheck above exercised the replacement method.
